## About

I’m Isaiah Marin, a Robotics and Embedded Systems graduate with hands-on experience in embedded programming, electronics, mechanical prototyping, industrial maintenance, automation troubleshooting, and system integration.

This portfolio highlights projects that connect software logic to real-world hardware behavior. Each project is presented as a professional case study with an overview, system design, testing process, engineering challenges, results, technologies used, and supporting evidence.

## Featured Projects

### Smart Temperature-Controlled Desk Fan
AVR-based embedded control system using temperature sensing, PWM fan control, servo movement, button input, buzzer feedback, and potentiometer-based manual control.

Technologies: AVR C, ATmega328P, Microchip Studio, PWM, ADC, DHT11, servo control

### Harvest Hawk
Agricultural robotics and embedded sensing platform designed for environmental monitoring, sensor integration, and field data collection.

Technologies: ESP32, I2C, BMP390, VEML7700, AM2320, environmental sensing, data collection

### ModuGrip
Motorized drawer-opening assist system using embedded control, custom 3D-printed hardware, actuator testing, and mechanical iteration.

Technologies: Arduino, motor control, 3D printing, CAD, rapid prototyping, testing

### Automated Page Turner
Assistive embedded systems prototype designed to turn book pages using controlled motor actuation, mechanical grip, and real-world prototype testing.

Technologies: ESP32, N20 gear motor, motor control, mechanical design, assistive technology

### Pipe Viper
Compact inspection robot focused on electrical integration, constrained hardware layout, camera-based inspection, and practical robotics troubleshooting.

Technologies: electrical integration, robotics, camera systems, hardware design, system integration

### Python Plane Classifier
Python machine learning project that classifies aircraft type from radar-style input data using a decision tree model and user-driven predictions.

Technologies: Python, scikit-learn, machine learning, decision trees, classification, data processing
