About Me

Building practical systems that solve real problems

I am a Robotics and Embedded Systems student with experience building projects that combine software, electronics, and physical design. My work ranges from embedded control systems and assistive devices to inspection systems, agricultural monitoring concepts, and machine learning tools. What connects all of these projects is the same mindset: identify a real problem, design a solution, build something functional, and improve it through testing.

This site is organized around six program objectives. Each objective includes two projects and explains how those projects demonstrate the specific technical skills and problem-solving approach expected in Robotics and Embedded Systems.

Program Objectives

How my work meets the major learning outcomes

Objective 1: Design and program embedded systems using microcontrollers, digital I/O, and control logic

These projects show my ability to build microcontroller-based systems that combine hardware inputs, outputs, and programmed logic into a working design. In both cases, I had to connect components correctly, write the control code, and verify that the system behaved reliably.

Smart Desk Fan AVR Project Automated Page Turner

Objective 2: Integrate sensors, actuators, and electromechanical components into functional systems

These projects demonstrate how I combine motors, sensing elements, and physical mechanisms into complete systems. The focus here is not just wiring parts together, but making the electronic and mechanical sides work together as one solution.

Harvest Hawk ModuGrip

Objective 3: Apply control methods, system behavior analysis, and user interaction to embedded solutions

These projects reflect how I design systems that respond to input, change modes, and behave predictably in real use. They show my understanding of how control logic, human interaction, and physical movement come together in a functioning embedded device.

Smart Desk Fan AVR Project ModuGrip

Objective 4: Prototype, test, troubleshoot, and refine robotics or embedded hardware systems

These projects show my ability to work through real build issues and improve a design through testing. They represent hands-on engineering work where iteration mattered, including fixing mechanical behavior, adjusting parts, and validating the final result.

Automated Page Turner Pipe Viper

Objective 5: Use software and data tools to support technical problem-solving and system development

These projects demonstrate how software supports engineering decisions. One project focuses on using Python and machine learning to classify aircraft, while the other uses field data and analysis as part of a larger robotics concept and system evaluation process.

Objective 6: Communicate technical work through documentation, demonstrations, and project presentation

These projects show that I can present engineering work clearly through videos, evidence, supporting visuals, and technical explanation. Strong engineering work is not just about building something, it is also about showing how it works and why the design decisions matter.
