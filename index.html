About Me

Building practical systems that solve real problems

I am a Robotics and Embedded Systems student with experience building projects that combine software, electronics, and physical design. My work ranges from autonomous crop monitoring concepts to inspection systems, assistive devices, embedded control systems, and machine learning tools. What connects all of these projects is the same mindset: identify a real problem, design a solution, build something functional, and improve it through testing.

This site is organized around six program objectives. Each objective includes two projects and explains how those projects demonstrate the specific technical skills and problem-solving approach expected in Robotics and Embedded Systems.

Smart Desk Fan AVR Project

Click cue: Open the Smart Desk Fan project page in a new tab or click into it.

This is one of my strongest embedded systems projects because it combines multiple hardware and software elements into one working system. It uses an AVR-based Elegoo Uno R3 to control a DC motor fan, a servo for oscillation, a buzzer for feedback, a button for mode switching, a potentiometer for manual input, and a DHT11 sensor for temperature and humidity readings.

What makes this project especially important is that it demonstrates PWM, ADC, digital I/O, timer control, and low-level embedded programming. I also include a schematic and build verification evidence, which makes it a strong example of both technical depth and proof of work.
