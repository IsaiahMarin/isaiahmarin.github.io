Robotics Project

Harvest Hawk

Harvest Hawk is an agricultural monitoring concept focused on collecting environmental data that can support smarter field awareness and better decision-making. The project combines embedded systems planning, sensor integration, and system-level design for a robotics-based crop monitoring platform.

View Project Evidence See Technical Breakdown

Project Overview

Harvest Hawk was designed as a system that could monitor environmental conditions relevant to agriculture by using an embedded controller and multiple sensors. The goal was to create a platform that could gather useful field data, including atmospheric pressure, altitude-related data, light levels, temperature, and humidity.

What makes this project important is not just the idea itself, but the way it applies embedded systems thinking to a real-world problem. It required choosing compatible sensors, planning communication between devices, and structuring the hardware so that the system could scale as more components were added later.

Key Skills Demonstrated

  • Embedded systems planning with an ESP32 microcontroller
  • I2C sensor integration and shared bus design
  • Environmental sensing for agriculture-focused applications
  • Power distribution and wiring layout planning
  • System-level design for future expansion
  • Technical documentation and schematic creation

Technical Breakdown

How the system is structured

Main Controller

Harvest Hawk uses an ESP32 as the main controller. The ESP32 was selected because it provides strong flexibility for embedded applications, including enough processing capability, useful GPIO access, and support for I2C communication. That made it a good fit for connecting multiple environmental sensors in a single system.

Sensor Suite

The project uses three main sensors. The BMP390 provides barometric pressure and altitude-related data, the VEML7700 measures ambient light levels, and the AM2320 handles temperature and humidity sensing. Together, these components create a more complete environmental picture that could support agricultural monitoring and analysis.

I2C Communication Design

One of the strongest technical parts of this project is the use of a shared I2C bus. Instead of assigning a separate set of wires for every sensor, the design uses common SDA and SCL lines across the sensor group. This reduces wiring complexity and makes the system easier to organize, troubleshoot, and expand.

In the schematic, GPIO21 is used for SDA and GPIO22 is used for SCL. Pull-up resistors are included on both communication lines to support stable I2C operation.

Power and Signal Layout

The sensor modules are powered from the ESP32’s 3.3V rail, with shared ground across the full system. A decoupling capacitor is included to help stabilize the sensor power line near the BMP390. This reflects proper embedded hardware practice by accounting for signal and power stability, not just basic connectivity.

Engineering Value

Harvest Hawk demonstrates embedded systems thinking because it required part selection, communication planning, electrical layout decisions, and documentation. Even though the project is presented here as a sensor integration and monitoring concept, it still reflects the real design work needed to build a functioning agricultural robotics platform.

Component Summary

Core hardware used in the design

ESP32

Serves as the main embedded controller for the system and manages communication with all connected sensors.

BMP390

Measures barometric pressure and supports altitude-related sensing for environmental monitoring.

VEML7700

Measures light intensity, which can help track environmental conditions related to field exposure and daylight.

AM2320

Measures temperature and humidity, adding important atmospheric data to the sensing package.

I2C Bus

Allows multiple sensors to share the same communication lines, reducing wiring and improving expandability.

Pull-Up Resistors and Capacitor

Support reliable communication and cleaner power behavior, which helps make the design more stable and technically complete.
