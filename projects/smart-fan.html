Embedded Systems Project

Smart Temperature-Controlled Desk Fan

This project is an AVR-based embedded system built on an Elegoo Uno R3 using the ATmega328P. It combines a DC motor fan, servo motor, DHT11 sensor, potentiometer, push button, buzzer, transistor motor driver, and diode protection into one working control system. The project demonstrates low-level embedded programming, PWM motor control, ADC input reading, digital I/O, and mode-based behavior in a single design.

View Demo Evidence See Technical Breakdown

Project Overview

The Smart Desk Fan System was designed to show how an embedded controller can manage multiple outputs and user inputs in a realistic physical system. In automatic mode, the fan behavior is tied to temperature logic while the servo sweeps side to side to simulate oscillation. In manual mode, the potentiometer directly controls fan speed. A push button changes modes, and a buzzer provides audible feedback during operation.

What makes this project strong is that it does not just turn a motor on and off. It combines sensing, control logic, timed actuation, and user interaction into a single embedded solution. It also includes a complete schematic, code, and build proof, which makes it one of the strongest examples in this portfolio for embedded systems design and hardware integration.

Key Skills Demonstrated

  • AVR microcontroller programming on ATmega328P
  • PWM control for DC motor speed
  • Servo motor sweep control using timers
  • ADC input reading from a potentiometer
  • Digital I/O for button and buzzer control
  • Sensor integration with DHT11 temperature and humidity readings
  • Mode switching between automatic and manual operation

Technical Breakdown

How the system works

System Components

The Smart Desk Fan uses an Elegoo Uno R3 with an ATmega328P microcontroller as the main controller. The fan itself is represented by a DC motor, which is driven through a 2N2222 NPN transistor. A 1N4001 diode protects the circuit from back EMF generated by the motor. A servo motor provides the oscillating fan motion, a DHT11 sensor provides temperature and humidity readings, a push button changes modes, a buzzer gives audible feedback, and a potentiometer allows direct user control during manual mode.

Automatic Mode

In automatic mode, the system reads the DHT11 sensor and uses the embedded logic to determine fan behavior. The fan speed is controlled through PWM, and the servo motor sweeps side to side to simulate the motion of a real oscillating desk fan. This mode demonstrates timer-based control, sensor reading, and output behavior tied to system conditions.

Manual Mode

In manual mode, the potentiometer becomes the primary control input. The analog value from the potentiometer is read through the AVR ADC and then converted into a PWM duty cycle for the fan motor. This gives the user direct control over fan speed and shows how analog input can be translated into real-time actuator behavior.

Embedded Programming Features

This project goes beyond simple Arduino-style scripting by using AVR programming concepts directly. The code uses timers for PWM output, register-level configuration for hardware behavior, ADC routines for analog reading, and digital input and output handling for the button and buzzer. The project also includes a custom DHT11 reading routine, which strengthens the embedded systems depth of the design.

Engineering Highlights

What this project demonstrates

PWM Motor Control

Fan speed is controlled using Pulse Width Modulation, allowing the motor output to be adjusted instead of simply switched on or off.

Servo Oscillation

The servo sweeps back and forth to simulate the movement of a real desk fan, showing timed motion control and actuator coordination.

Sensor Integration

The DHT11 sensor adds environmental input to the project and shows how a system can read real data and respond through programmed logic.

ADC Input Handling

The potentiometer is read through analog-to-digital conversion, then translated into usable control values for manual operation.

User Interaction

The push button and buzzer create a clearer user experience by allowing mode switching and audible confirmation.

Hardware Protection

The transistor driver and flyback diode show proper circuit design practices for safely controlling a motor from a microcontroller.
